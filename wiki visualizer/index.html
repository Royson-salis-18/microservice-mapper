Microservice Mapper

How this system works

Microservice Mapper watches a running Docker microservice system from the outside, over one SSH connection, installing nothing. From socket tables and container stats it builds a live dependency graph, finds the root cause when something breaks, predicts what would fail next, and draws it in 2D and 3D.

49 chapters in 8 parts. Read them in order, or start from the question you have below. Several chapters carry an interactive lab that runs the real formula with the real constants.
